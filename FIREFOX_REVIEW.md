# Firefox Add-ons Reviewer Build Notes

## Submitted extension

Open Web Translate is built from TypeScript/Vue source with WXT. The submitted Firefox package is generated; reviewers should use the source archive produced by the release workflow.

## Reproducible build environment

- OS used by CI: Ubuntu 24.04
- Node.js: 22.14.0 (from `.nvmrc`)
- pnpm: 9.15.0 (from `package.json` / release workflow)

## Build commands

```bash
corepack enable
corepack prepare pnpm@9.15.0 --activate
pnpm install --frozen-lockfile
pnpm typecheck
pnpm test
pnpm build:firefox
pnpm zip:firefox
```

Firefox unpacked output:

```text
.output/firefox-mv2
```

The packaged Firefox ZIP is generated by:

```bash
pnpm zip:firefox
```

## Source archive

For tags matching `v*`, `.github/workflows/release.yml` creates:

```text
.output/open-web-translate-<tag>-source.zip
```

using `git archive` from the exact tagged commit. The source archive excludes `.git`, build output, and `node_modules` by construction and includes the lockfile, source code, license, privacy policy, and third-party notices.

## Network behavior

Remote requests occur only for the provider selected by the user:
- Google Translate
- Gemini
- DeepL
- OpenRouter
- Hosted NVIDIA NIM
- Custom HTTP

Local providers:
- Ollama (loopback only)
- Local HTTP (loopback only)
- Chrome Built-in AI when supported

New installs must acknowledge the first-run data-transfer notice before remote translation requests are permitted.
